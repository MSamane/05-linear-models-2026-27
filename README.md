# Lecture 5: Linear Models

Data Science and Machine Learning for Geoscientists  
Academic year: 2026–27  
Lecturer: Samaneh A. Mofrad

## About this lecture

Using marine sediment data, we practise predicting porosity with linear regression
and classifying samples with logistic regression. We also explore gradient descent,
build scikit-learn pipelines and evaluate model predictions.

## Notebooks

1. [Regression with Linear Models](01-Regression-with-Linear-Models.ipynb)
2. [Classification with Linear Models](02-Classification-with-Linear-Models.ipynb)
3. [Optional: Electrocardiograms](03-Optional-Electrocardiograms.ipynb)

Open the notebooks in JupyterLab, Jupyter Notebook or VS Code with a Python 3
kernel. Keep the `Datasets` and `img` folders beside the notebooks.
Required libraries: NumPy, pandas, Matplotlib, seaborn and scikit-learn.

## Download the materials

You have two options. Neither requires a GitHub account for this public repository.

### 1. Download ZIP

Click **Code → Download ZIP**, unzip the folder, then open the notebooks locally.

### 2. Use Git

[Install Git](https://git-scm.com/install/) if needed, selecting your operating system.

Click **Code → HTTPS**, copy the repository link, then run this in a terminal,
replacing the placeholder with the copied link:

```bash
git clone PASTE_THE_COPIED_LINK_HERE
```

Open the notebooks inside the downloaded folder. To get later updates, including
new materials and solutions, run this **inside the cloned folder**:

```bash
git pull
```

For either option, work in a separately named copy of each notebook in the same
folder, keeping the original unchanged. Git updates will not update your personal
copy. You do not need to fork the repository or push your work.
